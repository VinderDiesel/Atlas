# 架构决策记录（ADR）

每个影响架构走向的决策都必须在这里留档。格式如下：

```
# ADR-XXXX：<决策标题>

- 日期：<YYYY-MM-DD>
- 状态：proposed | accepted | deprecated | superseded
- 相关：<链接到代码 / 评测报告 / 其他 ADR>

## 背景
<为什么要做这个决策，约束是什么>

## 备选方案
<列出 ≥2 个方案及其优劣>

## 决策
<选了什么>

## 理由
<为什么选它，关键权衡是什么>

## 代价与限制
<这个决策带来什么问题，什么情况下应该重新评估>

## 验证方式
<如何证明这个决策是对的，什么数据能证伪>
```

**重要**：ADR 的价值不在于记录"选了什么"，而在于记录**"为什么没选另一个"**和**"什么情况下应该推翻它"**。
评审/协作时能讲清这两点，比背出技术栈更有说服力。
