# Atlas 术语表

> 与 `AGENTS.md` 第 3 节完全一致。**新增术语必须同时更新两处。**
> 术语不统一的后果：LLM 生成的代码、注释、文档会出现同义词混用，
> 导致语义层定义与实际行为脱节。

| 术语 | 含义 | 禁止混用的词 |
|---|---|---|
| **Metric** | 已注册的指标定义（YAML 一等对象） | "字段"、"别名"、"标签" |
| **Measure** | 基础度量，可被聚合的物理列 | "指标"（易与 Metric 混淆） |
| **SemanticModel** | 指标与维度绑定的逻辑模型，指向物理表 | "宽表"、"模型" |
| **Dimension** | 可分组/筛选的业务维度 | "字段" |
| **Plan**（指标计划） | 问句解析后的结构化意图 | "Query"（后者指 SQL） |
| **Compiler** | Plan → SQL 的确定性转换器 | "生成器" |
| **Generator** | LLM/LoRA 候选 SQL 生成器 | "编译器" |
| **Guard** | 只读 SQL 安全网关 | "防火墙"（保留给网络层） |
| **EX** | Execution Accuracy | "准确率"（不精确） |
| **Plan Acc** | 逻辑计划与标注一致率 | — |
| **Gold set** | 自建黄金评测集 | "测试集"（含糊） |
| **Snapshot** | 固定数据快照，绑定 git sha | "数据库" |
| **RowPolicy** | 行级权限策略 | "权限表" |
| **Agent** | LangGraph 状态机编排 | "Bot"、"助手" |
| **FIBO** | Financial Industry Business Ontology，金融业务本体，项目的语义锚点（ADR-0007） | 泛指时的"本体" |
| **fibo_alignment** | 语义对象 → FIBO 概念 IRI 的映射（L2 概念对齐层，挂 custom_extensions） | "映射"（含糊）、"标签" |
| **Supersedes** | 指标版本升级时的取代关系 | "覆盖"、"替换" |
| **Schema Linking** | 从大量表中选出相关表的过程 | "表选择" |
| **SC**（Self-Consistency） | 多次采样按执行结果聚类的投票 | " ensemble " |

## 容易写错的时态

| 场景 | 正确时态 | 错误时态 |
|---|---|---|
| 功能已实现并测试 | 已实现 | — |
| 功能有代码但未测试 | 已实现，待验证 | 已实现 |
| 只有设计方案 | 计划/设计中 | 已实现、已上线 |
| MVP 可用 | 最小可用版本 | 生产级、企业级 |
| 数字未实测 | `<待填写>` | 任何具体数字 |
